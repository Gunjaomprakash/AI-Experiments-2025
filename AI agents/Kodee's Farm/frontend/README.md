# Frontend

This directory contains the frontend code for Kodee's Farm. It includes the following components:

- **index.html**: The main HTML file for the frontend.
- **package.json**: Contains the dependencies and scripts for the frontend.
- **tailwind.config.js**: Configuration file for Tailwind CSS.
- **src/**: Contains the source code for the frontend, including components, screens, and utilities.
- **public/**: Static assets such as videos and images.
