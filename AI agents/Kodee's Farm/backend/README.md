# Backend

This directory contains the backend code for Kodee's Farm. It includes the following components:

- **app.py**: The main entry point for the backend application.
- **requirements.txt**: Lists the Python dependencies required for the backend.
- **chromadb/**: Contains the ChromaDB setup and related files for managing the database.
- **config/**: Configuration files for the backend.
- **tools/**: Utility tools used by the backend.
- **uploads/**: Directory for storing uploaded files.
