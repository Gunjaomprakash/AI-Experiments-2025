# Kodee's Farm

Kodee's Farm is an AI-powered farming assistant designed to provide agricultural insights and tools for farmers. This repository is organized into two main parts:

- **backend/**: Contains the backend code, including database setup, API endpoints, and utility tools.
- **frontend/**: Contains the frontend code, including the user interface and static assets.

## Getting Started

### Prerequisites

- Python 3.8 or higher
- Node.js 14 or higher
- npm or yarn

### Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Gunjaomprakash/AI-Experiments-2025/tree/main/AI%20agents/Kodee's%20Farm-git
   ```

2. Navigate to the backend directory and install dependencies:
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

3. Navigate to the frontend directory and install dependencies:
   ```bash
   cd ../frontend
   npm install
   ```

4. Run the application:
   - Start the backend server.
   - Start the frontend development server.
